# Changelog

## [1.1.0] - 2026-11-08

- Updating an image keeps existing files in place (DOS system disks stay bootable).
- `.f12` files open with the plugin.
- Installer: asks when 7-Zip is using the plugin, no restart prompt, removes
  the copy from a previous 7-Zip folder, silent mode never stops at a dialog.
- CI: format check, Node.js 24 actions.
